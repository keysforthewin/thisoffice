# Scrollable Stats TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the wall-mounted Stats TV clickable (focus camera) and wheel-scrollable through its stat pages, pausing auto-cycle while focused.

**Architecture:** Rides the existing monitor focus-mode rails: TV screen plane gets `userData.monitorTarget: 'tv'` + the same click/hover handlers as `MonitorScreen.tsx`; `FocusControls` in `CameraRig.tsx` gets a `'tv'` branch where a wheel tick is ±1 page (stored in the existing `focusScroll` counter, reset to 0 on every camera-mode change); `WallTV.tsx` freezes the clock page at focus entry and adds `focusScroll`. `subjectFor('tv')` already frames the TV, `tvContent()` already wraps any integer index.

**Tech Stack:** React Three Fiber, zustand, vitest.

**Spec:** `docs/superpowers/specs/2026-07-25-tv-scroll-design.md`

## Global Constraints

- No new store state — reuse `focusScroll`.
- `tvContent.ts` page-building logic unchanged; only the new pure helper is added.
- Tests never touch real `data/office.json` (server-side concern; not applicable here, listed per repo policy).

**Files:**

**Interfaces:**
- Produces: `tvPageIndex(autoPage: number, focusedBase: number | null, focusScroll: number): number` — displayed page index: `focusedBase + focusScroll` when `focusedBase !== null` (TV is focused; base = clock page captured at focus entry), else `autoPage`. - [ ] **Step 3: Implement** — append to `web/src/scene/tvContent.ts`:

```ts
/** Displayed page index: while the TV is camera-focused (`focusedBase` set at
 *  focus entry) the clock is ignored and the wheel offset applies; result may
 *  be negative — `tvContent` wraps it modulo the page list. */
export function tvPageIndex(autoPage: number, focusedBase: number | null, focusScroll: number): number {
  return focusedBase === null ? autoPage : focusedBase + focusScroll;
}
```

    const onWheel = (e: WheelEvent) => {
      e.preventDefault();
      const st = useStore.getState();
      if (target === 'tv') {
        // signed page offset — tvContent wraps it, so no clamping
        st.setFocusScroll(st.focusScroll + (e.deltaY > 0 ? 1 : -1));
        return;
      }
      const raw = target === 'boss' ? bossScreenLines(st.office?.inbox ?? []) : (st.monitorHistory[target] ?? []);
      const total = wrapLines(raw, MONITOR_COLS).length;
      const step = e.deltaY < 0 ? SCROLL_ROWS_PER_TICK : -SCROLL_ROWS_PER_TICK;
      st.setFocusScroll(clampOffset(st.focusScroll + step, total, MONITOR_ROWS));
    };

- [ ] **Step 2: Add handlers and focused paging** inside `WallTV`. After the `drawnKey` ref, add:

```ts
  const gl = useThree((s) => s.gl);
  /** clock page captured when focus on the TV begins; null while unfocused */
  const focusBase = useRef<number | null>(null);

  const focusTv = (e: ThreeEvent<PointerEvent>) => {
    // while pointer-locked, clicks steer the fly cam — never steal them
    if (document.pointerLockElement) return;
    // in build mode a click drags the TV along the wall, never focuses
    if (useStore.getState().buildMode) return;
    e.stopPropagation();
    const st = useStore.getState();
    const cur = st.cameraMode;
    if (cur.kind === 'focus' && cur.target === 'tv') return;
    const pose: CameraPose = {
      position: e.camera.position.toArray() as [number, number, number],
      quaternion: e.camera.quaternion.toArray() as [number, number, number, number],
    };
    gl.domElement.style.cursor = '';
    st.setCameraMode(enterFocusMode(cur, 'tv', pose));
  };
  const hoverStart = () => {
    if (document.pointerLockElement) return; // crosshair raycast owns hover while flying
    if (useStore.getState().buildMode) return; // build mode's own cursor feedback wins
    useStore.getState().setMonitorHover('tv');
    gl.domElement.style.cursor = 'pointer';
  };
  const hoverEnd = () => {
    const st = useStore.getState();
    if (st.monitorHover === 'tv') st.setMonitorHover(null);
    gl.domElement.style.cursor = '';
  };
```

Replace the `useFrame` body:

```ts
  useFrame(({ clock }) => {
    const autoPage = Math.floor((clock.elapsedTime * 1000) / TV_PAGE_MS);
    const st = useStore.getState();
    const focused = st.cameraMode.kind === 'focus' && st.cameraMode.target === 'tv';
    if (!focused) focusBase.current = null;
    else if (focusBase.current === null) focusBase.current = autoPage;
    const page = tvPageIndex(autoPage, focusBase.current, st.focusScroll);
    const content = tvContent(st.stats, page);
    const key = JSON.stringify(content);
    if (key === drawnKey.current) return;
    drawnKey.current = key;
    drawTvPage(ctx, content.page, content.pageNum, content.pageCount);
    texture.needsUpdate = true;
  });
```
